# Деплой Zetrix на Render + GitHub Pages

## Архитектура
- **Фронтенд** (HTML/CSS/JS) → GitHub Pages (бесплатно)
- **Бэкенд** (Node.js + SQLite) → Render.com (бесплатно)

---

## Шаг 1. Подготовка репозитория

Убедись, что в корне проекта есть файл `render.yaml`.

---

## Шаг 2. Деплой бэкенда на Render

1. Зарегистрируйся на [render.com](https://render.com) через GitHub.
2. В Dashboard нажми **New +** → **Blueprint**.
3. Выбери свой репозиторий с Zetrix.
4. Render сам найдёт `render.yaml` и создаст сервис `zetrix-api`.
5. После деплоя скопируй URL сервиса (например `https://zetrix-api.onrender.com`).

> **Важно:** на бесплатном тарифе сервер "засыпает" после 15 минут бездействия. Первый запрос после сна может занять 30–60 секунд.

---

## Шаг 3. Настройка CORS (обязательно)

В `server/index.js` есть переменная окружения `FRONTEND_URL`. Добавь её в настройки сервиса на Render:

1. На Render открой свой сервис → **Environment**.
2. Добавь переменную:
   - `FRONTEND_URL` = `https://ТВОЙ-НИК.github.io`
3. Нажми **Save Changes** — сервер перезапустится.

Если не хочешь заморачиваться с доменом, в продакшене CORS разрешает любой origin (но лучше ограничить для безопасности).

---

## Шаг 4. Настройка фронтенда

Открой `api.js` и замени `RENDER_API` на свой URL с Render:

```javascript
const RENDER_API = 'https://zetrix-api.onrender.com/api';
```

Закоммить и запушь изменения:
```bash
git add .
git commit -m "feat: switch API to Render"
git push
```

---

## Шаг 5. GitHub Pages

1. Открой репозиторий на GitHub → **Settings** → **Pages**.
2. Ветка: `main` (или `master`), папка: `/ (root)`.
3. Сохрани. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ТВОЙ-НИК.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ`

---

## ⚠️ Ограничение SQLite на Render Free

На бесплатном тарифе Render **не сохраняет файлы** между перезапусками сервера (ephemeral filesystem). Это значит:
- При каждом новом деплое или после сна сервера SQLite база **создаётся заново**.
- Все пользователи и ключи **пропадают**.

**Решения:**
1. **Render Disk** (платно, ~$5/мес) — постоянное хранилище.
2. **Supabase** (бесплатно) — облачная PostgreSQL вместо SQLite.
3. **Просто не деплоить часто** — данные живут пока сервер не уснёт/не перезапустится.

## Проверка

1. Открой `https://ТВОЙ-НИК.github.io/login.html`
2. Зарегистрируй пользователя
3. Зайди в админку (`ADMINSYSTEM` / `12345678`) — должен быть виден новый пользователь
4. Создай ключ в админке → активируй в профиле

Всё должно работать через единый API на Render.
